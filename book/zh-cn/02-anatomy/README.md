# 第二章：编程智能体解剖

Last updated: 2026-07-27

> *你无法有效驾驭一个自己不了解的工具。本章帮助你建立心智模型——然后拿起螺丝刀，把这台机器拆开。*

在[第一章](../01-prompt/README.md)中，你学习了如何向编程智能体下提示词。但要做好这件事，光靠一些套路是不够的——你还需要理解*为什么*某些方法有效，而另一些会失败。本章通过剖析编程智能体的本质来打牢这一基础：它们究竟是什么，如何做出决策，在哪些地方容易出问题，以及一个生产级智能体（Claude Code）如何把这些原理落成一套可扩展的完整架构。

本章从心智模型逐步走向机械细节：

1. **这台机器如何运转** — [编程智能体工作原理](how-agents-work.md) 追溯了从内联补全到智能体化编程的演进历程，并解释了每个智能体共有的三大支柱：系统提示词、工具以及上下文策略。理解这三大支柱，是在事情出错时调试智能体行为的关键所在。

2. **该给它们多大自由度** — [自治级别与人工干预](autonomy-levels.md) 提供了一个框架，帮你判断何时可以让智能体自由运转，何时需要紧紧把控。核心原则是：低风险的重复性工作给予高度自治；业务关键逻辑则需严格监督。本节还整理了最常见的失败模式及其预防方法。

3. **人和智能体如何协作** — [人机协作模式：从探索到可验证交付](human-agent-collaboration-modes.md) 说明如何根据需求清晰度、风险和验证成本选择工作模式。它把 vibe coding 重新定位为探索，把规格定位为意图契约，把验证定位为智能体产出进入真实交付前的关口。

4. **平台深度解析** — [将 Claude Code 作为智能体框架](claude-code.md) 展示一个智能体如何把三大支柱落成具体架构。它的四层结构（内存、扩展、集成、SDK）与上面的心智模型直接对应，掌握它能为你理解任何智能体系统建立可迁移的直觉。

5. **上下文与委托** — [上下文管理原则](context-management.md) 提供保持智能体工作集清洁的纪律。[子智能体](sub-agents.md) 介绍为隔离任务生成具有特定范围的临时智能体，[智能体团队](agent-teams.md) 将此延伸至协调多个智能体处理更大型项目。

6. **扩展智能体** — [技能](skills.md) 和 [Hooks](hooks.md) 展示如何为智能体赋予新能力，并通过事件驱动的自动化将其接入开发工作流。[工具、MCP、CLI 与更多](MCP.md) 和 [为你的智能体打造专属工具](building-tools.md) 涵盖集成取舍、自定义工具和环境配置。

7. **综合实践** — [系统化思考](systematic-thinking.md) 把整个解剖学融会贯通。它教授将技能、子智能体、Hooks 等组合成生产级智能体系统的*组合原则*——包括治理设计、上下文隔离以及完整的架构示例。
