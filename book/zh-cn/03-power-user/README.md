# 第三章：成为高级用户

Last updated: 2026-07-28

> *使用编程智能体与精通它之间的差异，就像会开车与调度一支车队之间的差异。*

[第二章](../02-anatomy/README.md)把这台机器拆开了：智能体如何工作、该给多大自由度，以及 Claude Code 的内存、扩展与集成各层如何组装在一起。本章要把这套解剖学变成工程实践——正是这些系统和纪律，把从 AI 获得 2 倍效能的开发者与获得 10 倍效能的开发者区分开来。

本层包含四章。目前一章已完成，其余三章的提纲如下，尚未加入目录。进度见仓库根目录的
[`ROADMAP.md`](../../../ROADMAP.md)。

1. **编排层（Orchestration Layer）** — 如何设计位于单个智能体之上的那一层：在会话、智能体和工作流之间调度工作，决定哪些任务自主运行、哪些交互执行，并把子智能体、Hooks 和 Skill 组合成可复用的流水线，而不是一次性的技巧。

2. **工程框架（Engineering Frameworks）** — 让智能体辅助开发变得可靠的可复用结构：项目脚手架、验证闭环、任务拆解模板，以及围绕智能体原生工程正在形成的各种框架。

3. **规格编码（Spec Coding）** — 深入规格优先的开发方式：撰写智能体可以直接执行的规格、六维需求体系，以及从规格到已验证变更的交付闭环。

4. **[接手老代码库](legacy-codebases.md)** — 让智能体面对大型存量系统的高级用户策略：老系统中的三种债务、理解—约束—验证三层控制，以及通过「Characterization Test → Seam → 增量重构」保持智能体驱动的改动可逆。

---

**你已经走过的路：** [第二章](../02-anatomy/README.md)给了你完整的解剖学——心智模型、自治框架、协作模式，以及从上下文管理到系统化组合的整套 Claude Code 工具箱。
