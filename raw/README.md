# Raw Notes

Last updated: 2026-07-27

Source notes, research snippets, and rough material before it is promoted into
`book/`. Notes live flat in this folder, named by topic.

**Tracking lives in [`ROADMAP.md`](../ROADMAP.md)** — its "Raw intake" table
maps every note to a target chapter and records how much of it has been used.
Don't duplicate that status here.

Promote material with the `book-chapter-writer` skill: it drafts into
`book/en/`, then `zh-translator` mirrors into `book/zh-cn/`. Publishable
chapters belong under `book/<lang>/`, never here. Notes are kept after
promotion for traceability.
